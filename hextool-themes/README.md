# hextool-themes

Upload isi folder ini ke root repo GitHub `hextool-themes` (branch `main`).

- `index.json` : daftar tema (id, name, version)
- `themes/<id>/theme.json` : warna + nama file gambar
- Tambah tema baru: buat folder `themes/<id>/`, tambahkan ke `index.json`.
- Update tema: naikkan `version` di `index.json` DAN `theme.json`.
- Batas: gambar <= 2 MB (png/jpg/jpeg/webp), id hanya a-z 0-9 _ -
